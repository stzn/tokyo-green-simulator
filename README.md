# Urban Green Twin Tokyo

**都市の自然の解像度を上げ、価値を可視化する。**

東京23区の3D建物（PLATEAU）、都道の街路樹14.4万本、公園を重ね合わせ、都市の緑の「現状」と、屋上・壁面緑化による「将来価値」をブラウザ上で試算するWebGISです。研究室訪問やPoC提案のデモとして使うことを想定しています。

## できること

| 機能 | 内容 |
| --- | --- |
| 3Dベースマップ | PLATEAUの建物を高さ（measuredHeight）で押し出して表示。回転・傾き・ズーム |
| 緑地・樹木レイヤー | 公園ポリゴン、街路樹の3Dピラー（高さ＝樹高、色＝樹種）とヒートマップ。レイヤーごとに表示を切り替えられる |
| 属性表示 | 樹木（樹種・樹高・幹周・推定樹齢・年間CO2吸収量・路線）、公園（面積・管理者）、建物をクリックで表示 |
| 絞り込み | 樹種（407種、検索つき）と行政区。GPUフィルタのため14万本でも再アップロードしない |
| 緑化シミュレーション | 建物を選び、屋上・壁面緑化率を指定して、表面温度低下・冷房等の電力削減・CO2削減を試算。「緑化する」で屋上と壁面に緑が伸びる演出が入り、エリア合計に加算される |
| 計算根拠の公開 | 「計算方法と出典」から、式・係数・出典リンク、計算に含めていない効果を確認できる |

## セットアップ

Node.js **20.19以上または22.12以上**が必要です（Vite 8の要件。v24でも動作確認済み）。`node -v` で確認し、足りない場合は nvm・nodebrew などで切り替えてください（nvm なら `.nvmrc` があるので `nvm use` で切り替わります）。

```bash
npm install
npm run dev        # http://localhost:5173
```

### データの再取得

`public/data/` の生成済みデータはリポジトリに含めています。最新データに更新する場合のみ実行してください。

```bash
npm run data:trees   # 東京都オープンデータ → public/data/trees.json（約1分）
npm run data:parks   # Overpass API → public/data/parks.geojson（混雑状況によって10〜30分）
```

`data:parks` は区ごとのOverpass応答を `scripts/.cache/parks-raw/` に保存します。途中で失敗しても再実行すると続きから取得し、変換ルールを変えたときも再取得せずに作り直せます。

## 開発

```bash
npm test             # Vitest（振る舞いテスト）
npm run typecheck    # tsc --noEmit
npm run build
```

テストは **BDD**（振る舞いを先にテストで書き、それから実装する）で書いています。`describe('機能: …')` → `describe('シナリオ: …')` → `it('Given … / When … / Then …')` の形です。WebGLはjsdomで動かないため、次のように範囲を分けています。

- 計算・データ変換・ストア・レイヤー生成関数：単体で検証
- UI：地図（`MapView`）をモックにして、ストア経由の振る舞いを検証
- 実描画：ブラウザで確認

## 数値の扱いと既知の制約

- **係数の出典**：`src/lib/simulation/coefficients.ts` の係数は、すべて公的資料で出典を確認済みです（2026年9月）。各係数に資料名・該当箇所・URLを持たせ、`coefficients.spec.ts` で「確認済み・URLあり」を検証しています。

  | 項目 | 値 | 出典 |
  | --- | --- | --- |
  | 屋上の表面温度低下 | 目安15℃／最大23.7℃ | 環境省「ヒートアイランド対策ガイドライン改訂版」H25、国交省 報道発表 H19.8.24 |
  | 壁面の表面温度低下 | 最大10℃ | 同ガイドライン（東京都「壁面緑化ガイドライン」を引用） |
  | 屋上緑化の冷房等の電力削減 | 9.40 kWh/m²・年（5.218 kg-CO2 ÷ 0.555） | 国交省「低炭素まちづくり実践ハンドブック 資料編」H25 |
  | 電力の排出係数 | 0.421 kg-CO2/kWh | 東京電力EP 2024年度 |
  | スギ換算 | 8.8 kg-CO2/本・年 | 林野庁 |
  | 街路樹（高木）1本のCO2吸収 | 39.6 kg-CO2/年（0.0108 t-C） | 日本国温室効果ガスインベントリ報告書2025 表6-53 |
  | 樹齢推定 | 樹種別の回帰式（17樹種） | 国総研「公園樹木管理の高度化に関する研究」H22 表-12 |

- **計算に含めていないもの**：屋上・壁面の植物によるCO2固定、雨水貯留、壁面の冷房削減、植栽タイプ別の差、周辺気温の低下。公的な根拠が見つからない、または国の算定でも計上しないためです。
- **推定値**：樹齢は回帰式のある17樹種だけを推定します（CSVの「サクラ」はソメイヨシノ、「スズカケノキ」はプラタナスの式を適用）。それ以外は「推定式なし」と表示します。CO2吸収量は国の算定に合わせて高木のみを対象とし、中木は「対象外」です。
- **公園の管理者**：OSMの `operator`／`owner` タグを使います。タグが無い場合は、名称に「都立」「区立」とあるときだけ推定し、それ以外は「不明」と表示します（現状、約9割が不明）。区の公園一覧のオープンデータは区によって有無・形式がまちまちで、突き合わせには使えませんでした。
- **公園の範囲**：Overpassの区域検索は区境をまたぐポリゴンも返すため、区外の公園（例: 戸田公園）が一部含まれます。
- **建物形状**：タイル境界をまたぐ建物は、ピックしたタイル内の形状で外周長を計算します（屋根面積はPLATEAUの属性値を使うため影響しません）。
- **描画方式**：deck.gl 9.4 と MapLibre 5 の interleaved モードではピッキングが効かなかったため、deck.glのcanvasを地図の上に重ねる方式にしています。MapLibre 6 は deck.gl 9.4 が未対応のため 5 系に固定しています。
- **依存の脆弱性警告**：`npm audit` で、deck.gl geo-layers が間接的に依存する3D Tiles／glTF／画像パーサのDoS系の警告が出ます。本アプリは信頼できるPLATEAUのMVTしか読み込まず、修正版の提示がメジャーダウングレードのため、現時点では受け入れています。
